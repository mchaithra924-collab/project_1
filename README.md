# Daylight — Student Task Manager

A lightweight student planner built with HTML, CSS, and vanilla JavaScript. Organize coursework, track daily progress, and keep a personal attendance streak—all from your browser.

## Features

- Add, edit, complete, search, filter, and delete tasks.
- Assign a subject, due date, and priority to each task.
- Track totals, completed tasks, tasks due today, and daily progress.
- Check in once per day and view your attendance history in a monthly calendar.
- See your current attendance streak and monthly check-in rate.
- Save tasks and attendance in browser local storage.
- Responsive layout for desktop and mobile.

## Getting started

No dependencies, build tools, or installation are required.

1. Download or clone this repository.
2. Open `index.html` in a modern web browser.
3. Add a task or mark your daily attendance.

The app stores data in the current browser on the current device. Clearing browser data or switching browsers/devices may remove or hide saved data. Attendance is a personal check-in tracker, not a shared class attendance system.
